모든 에셋은 `apps/web/public/assets/`에 **2x 해상도**로 들어 있습니다. 크기는 390 × 844 화면 기준(1x)입니다.

## 가져오는 방법 (Figma MCP)

1. Claude Code / Codex에 Figma MCP를 연결하고 `get_design_context`로 프레임을 읽습니다.
2. `download_assets`로 노드를 내보냅니다.
3. **주의:** 내보낸 이미지는 부모 프레임 배경색 위에 합쳐져서 투명도가 사라집니다.
   투명해야 하는 에셋(로고, 마스코트, 나뭇잎)은 `get_design_context` 응답의 원본 이미지(raw)를 받아
   Figma의 crop 값(width/height/left/top %)대로 잘라서 2x로 저장합니다.
4. Figma MCP가 주는 이미지 URL은 잠깐만 유효하고 비밀값처럼 다룹니다. 코드에서 직접 쓰지 말고 항상 파일로 저장하세요.
