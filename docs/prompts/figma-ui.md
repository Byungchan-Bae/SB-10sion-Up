## 목표
Figma 컨셉 이미지와 "최대한 똑같이" 보이게 구현한다. 레이아웃, 여백, 색, 글자 크기와 굵기,
둥근 모서리, 버튼 위치, 카드 그림자까지 이미지를 기준으로 맞춘다. 임의로 디자인을 바꾸지 않는다.
이미지에서 판단이 안 되는 부분은 추측해서 진행하되, 무엇을 추측했는지 HANDOFF.md "막힌 점 / 메모"에 적는다.

## 앱 소개
성북동의 유서 깊은 장소를 직접 걸으며 미스터리를 해결하는 야외 방탈출 게임.
EP.01 "사라진 편지": 1937년 성북동에서 사라진 편지의 수신인을 찾기 위해 네 장소를 돌며 단서를 모은다.
마스코트: 탐험모자를 쓰고 돋보기를 든 주황색 감 캐릭터 + SB 티셔츠를 입은 흰 새 캐릭터.

## 기술 규칙
- React + TypeScript + Vite (apps/web). 라우팅은 react-router 사용(pnpm add react-router).
- 화면 기준 폭 390px(iPhone). 모바일은 꽉 차게, PC에서는 max-width 430px로 가운데 정렬하고 양옆은 배경색.
- 높이는 100dvh, 하단 버튼과 탭바는 env(safe-area-inset-bottom) 고려.
- 스타일은 CSS Modules(*.module.css) + 공통 디자인 토큰(src/styles/tokens.css의 CSS 변수). UI 라이브러리 추가 금지.
- 일러스트(마스코트, 한옥, 나무, 배경, 사진)는 CSS로 그리지 않는다. 이미지 파일을 쓴다.
  apps/web/public/assets/ 아래에 두고, 아직 없는 파일은 같은 크기의 회색 박스 + 파일 이름 텍스트로 자리만 잡아 둔다.
  필요한 에셋 목록을 docs/design/ASSETS.md에 (파일 이름, 크기, 어느 화면에 쓰는지) 정리해서 디자이너가 Figma에서 내보낼 수 있게 한다.
- 에피소드, 장소, 문제, 단서 데이터는 코드에 하드코딩하지 말고 apps/web/src/data/episodes.ts에 모으고,
  타입은 packages/types에 정의한다. 나중에 API(apps/web/api/)로 옮길 수 있게 한다.
- 사용자 진행 상태(닉네임, 인증한 장소, 푼 문제, 모은 단서)는 지금은 localStorage에 저장한다.
- 끝내기 전에 pnpm build 통과, 모바일 화면(390px)에서 이미지와 나란히 놓고 비교 확인.

## 디자인 토큰 (이미지에서 추출한 값, 실제 Figma 값을 알면 그걸로 교체)
- primary(주황 버튼, 강조 텍스트): #F9A23B 근처, 눌림 상태 한 단계 진하게
- primary-soft(주황 연한 배경, 정보 박스): #FFF1DC 근처
- 배경 크림: #FFF8EE, 편지지/양피지: #F6E6C8, 세피아 화면 배경: #E9C99A 계열
- 제목 갈색: #5A3412 계열, 본문: #3B2A1A, 보조 텍스트: #8A7360
- 온보딩 설명 박스 3색: 주황 연한(#FFF1DC) / 초록 연한(#E9F7EA) / 파랑 연한(#E8F3FC)
- 버튼: 높이 약 52px, 모서리 반경 12px, 흰색 굵은 글자, 화면 양옆 여백 24px
- 카드: 모서리 16~20px, 부드러운 그림자
- 글꼴: 본문 Pretendard, 로고/큰 제목은 둥글고 두꺼운 손글씨 느낌
  (로고 "성북 트레저"는 이미지 에셋으로 처리, 화면 제목은 Pretendard ExtraBold로 시작)

## 성북동 A 인문산책 코스 (출처: 성북구 문화관광 https://www.sb.go.kr/tour/contents.do?key=6582)
순서: 길상사(출발) → 한국순교복자성직수도회 구 본원 → 이태준가옥(수연산방) → 심우장(도착)
- 길상사: 1960~80년대 말 삼청각, 청운각과 함께 최고급 요정이던 대원각 자리. 주인 김영한 여사가
  7천여 평 대지와 건물 40여 동을 법정 스님에게 시주해 절이 됨. 지금은 템플스테이 등 도심 속 문화공간.
- 한국순교복자성직수도회 구 본원: 1953년 설립된 한국 가톨릭 최초의 내국인 남자 수도회 본원.
  방유룡 신부 설계(1953). 라틴십자가 평면, 타원형 후진과 돔. 2015년 국가등록문화재 제655호.
- 이태준가옥(수연산방): 「문장강화」「무서록」의 상허 이태준 고택. 손녀가 전통찻집으로 운영.
  사랑방 문에 한지 대신 유리를 끼워 북악산 자락이 보임.
- 심우장: 만해 한용운이 1933년부터 1944년 6월 입적할 때까지 산 집. 「님의 침묵」 작가, 민족대표 33인.
  직접 심은 향나무가 있음.
장소별 좌표와 정확한 주소는 data 파일에 TODO로 두고, 확인된 값만 채운다.

### 3단계 — 탐험 지도 + 장소 인증 + 역사 이야기 (브랜치 `feat/place`)

```
3단계를 진행해라: docs/design/03-place-gilsangsa.webp의 "탐험 지도", "장소 인증 전", "장소 인증 후", "역사 내용".

1. 탐험 지도(/episode/ep01/map): 헤더 "탐험 지도", 위쪽 진행 카드(썸네일 + EP.01 사라진 편지 + 진행 표시).
   일러스트 지도 이미지 위에 아래→위로 이어지는 점선 경로와 장소 핀 4개:
   길상사(시작, 열림) → 한국순교복자성직수도회 구 본원 → 이태준가옥(수연산방) → 심우장.
   잠긴 장소는 회색 자물쇠 원, 열린 장소는 사진 원. 이전 장소의 단서를 찾아야 다음 장소가 열린다.
   핀 위치는 지도 이미지 기준 % 좌표로 data에 둔다. 열린 장소를 누르면 장소 인증 화면.
2. 장소 인증(/place/:id): 헤더 "장소 도착 인증", 장소 사진 + 마스코트, 장소 이름, 주소,
   3단계 표시(위치 권한 확인 → 현재 위치 확인 → 도착 인증 완료), "지금 위치로 인증하기",
   아래 말풍선 "도착을 인증하면 이곳에 담긴 역사이야기를 볼 수 있어요!".
   누르면 navigator.geolocation으로 현재 위치를 받아 장소 좌표와의 거리(하버사인)가 150m 이내면 통과.
   확인 중에는 버튼이 회색 "인증 대기중...". 실패하면 거리와 함께 안내.
   개발/시연용으로 URL에 ?demo=1이면 위치 확인을 건너뛰고 통과시킨다.
3. 역사 내용(/place/:id/story): 사진 + 장소 이름, "장소 이야기" 라벨, 제목
   "대원각에서 길상사로, / 나눔의 마음이 깃든 절", 본문(공통 프롬프트의 길상사 내용 기반),
   마스코트 말풍선 박스, "첫번째 단서 찾기"(주황), "AI 질문하기"(흰 버튼, 지금은 준비 중 안내).
끝나면 pnpm build, 이미지 비교, HANDOFF.md 갱신, 커밋, push, PR.
```
